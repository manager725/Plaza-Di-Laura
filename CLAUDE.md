# Plaza Di Laura: project rules

Clickable prototype of a redesigned bylaura.se (Laura Lindqvist's cosmetic tattoo clinic and academy, Kungsgatan 11, Göteborg). Process: the Pitch-to-Win Site Prompt v2 (Desktop\Ummrah site\docs\Pitch-to-Win-Site-Prompt-v2.pdf). Discovery notes: docs/phase-1-discovery.md.

@DESIGN.md

## How it is built
- Pages are generated by `_build/build.py` from `_build/content/*.json` (Swedish text in the HTML, English in data-en attributes swapped by site.js). Edit content or templates, then run `python -I _build/build.py`. Never hand-edit generated .html files.
- Readable CSS and JS live in `_build/src/css` and `_build/src/js` (never deployed). The build minifies them into `assets/css` and `assets/js` with the pinned esbuild in `_build/node_modules` (run `npm install` inside `_build` on a new machine). Always edit `_build/src`, never the minified files in `assets/`.
- Output is a static folder: index.html and 404.html at the root, relative asset paths, no build step for the host.
- The user deploys on Vercel themselves. Never deploy or publish. Don't commit unless asked.
- `_build/`, `docs/`, DESIGN.md and CLAUDE.md are internal and must never reach the client (see .vercelignore).
